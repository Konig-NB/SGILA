# SGILA Visual Vocabulary Sheets

These image sheets were generated with OpenAI image generation on 2026-08-05
for SGILA's visual-matching and pronunciation activities.

Each sheet uses a fixed 3-by-2 grid. Panels 1 through 5 contain one isolated
vocabulary subject on a plain background; panel 6 is intentionally blank. The
panel order is defined by `LESSON_WORDS` in `api/curriculum_enrichment.py`.
